## 🐛 BUGS ENCONTRADOS Y ARREGLADOS

### Bug 1 — Kalman `rms()` esperaba tuplas de 3 elementos
- **Síntoma:** `ValueError: not enough values to unpack (expected 3, got 2)`
- **Causa:** Bench mode entregaba pares `(a, b)` pero la función solo aceptaba `(z, x, _)` triple
- **Fix:** Refactor a `rms_pair()` con auto-detección de longitud
- **Resultado:** Kalman reduce RMS **57-62%** vs ruido sintético σ=1.2

### Bug 2 — Voice commander `dice` con `{}` vacíos
- **Síntoma:** `IndexError: Replacement index 0 out of range for positional args tuple`
- **Causa:** `info["reply"].format()` con placeholders vacíos cuando intent="dice"
- **Fix:** Branching especial para `intent == "dice"` extrayendo texto libre
- **Test verde:**
  - `aiion dice hola mundo` → `"hola mundo"` ✓
  - `aiion dice` → `"no has dicho qué decir"` ✓
  - `aiion sombra` → `"Modo sombra activado."` ✓

### Bug 3 — Kalman argparse consumía args del subparser
- **Síntoma:** `Uso: kalman.py bench <archivo.csv> <columna>` aunque se pasaran los args
- **Causa:** `parse_known_args()` + paso manual de `args2` a las funciones, sin bind correcto
- **Fix:** Refactor a `parse_args()` con `ns.cmd` + namespace y handlers dict-lambda
- **Resultado:** `bench CSV temp` ahora produce benchmark real:
  ```
  RMS Kalman:      1.9914
  RMS MediaMovil5: 1.4592
  Ganancia Kalman: -36.5%
  ```

### Bug 4 — `/tmp` no existe en Termux
- **Síntoma:** `FileNotFoundError: [Errno 2] No such file or directory: '/tmp/kalman_test.csv'`
- **Causa:** Termux usa `$PREFIX/tmp` no `/tmp`
- **Fix:** Uso de `/data/data/com.termux/files/usr/tmp/` para tests

### Bug 5 — Archivos `.bak` residuales
- **Síntoma:** 9 archivos `.bak` dispersos por skills (creados por tool `replace`)
- **Fix:** `find /skills -name "*.bak" -delete` — eliminados los 9
